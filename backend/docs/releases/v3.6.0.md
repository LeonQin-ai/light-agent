# light-agent v3.6.0

- SSH 单独报告认证失败、连接失败和远程命令失败。同一任务会拦截使用相同凭据的重复认证。跨会话复用可在「会话设置 → SSH 环境与本机凭据」中配置命名环境，会话凭据继续隔离。 [#292](https://github.com/LeonQin-ai/light-agent/issues/292)
- 漫剧工房的角色对白流程依次处理剧情因果、分镜、美术和声音，由总控合成九段式导演稿。角色档案可跨集复用外观和音色。
- 视频制作支持混合使用 3 秒和 4 秒镜头，生成画面前校验台词长度。剪辑支持声音提前入场、余音跨镜、静默和本地字幕卡。
- 中英文 README 上线《铜铃过山》连贯修正版，支持内嵌播放和 720p 下载。
