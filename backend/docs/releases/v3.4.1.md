# light-agent v3.4.1

- 漫剧工房新增文生视频模式，支持百炼 HappyHorse、百炼可灵和火山方舟 Seedance。每个分镜可生成 3 或 4 秒竖版短片，按剧情顺序合成含配音和字幕的 MP4。Seedance 的 3 秒片段由 4 秒源视频裁剪而来。已完成的片段和待查询的生成任务编号可在继续制作时复用。
- Model routes 支持单独配置和测试文生图与文生视频路由。制作 UI 时可将文生图模型的产物直接保存到项目并用于页面。
- 一键导入小说时可指定分镜模型和画面模型。单章导入保留指定集号，分镜直接生成结构化 JSON，减少重复读取和校验。
- 漫剧出图与配音可并行执行，校验通过后自动合成。重试时复用已验证素材，剪辑完成后立即交付。
- 漫剧任务可统一选择分镜、文生图和视频路由。角色三视图生成正面、侧面和背面设定，各镜头复用同一套角色外观描述。
- 成片去除镜头计数和统一添加的雨丝，保留原画以及配音、字幕。
- 修复 Windows 断点续跑时未识别保存的视频任务编号的问题。
