## light-agent 3.2.0

- Add fast mode (default): parallel read-only pre-pass workers, a delegate sub-agent tool and a simple acceptance gate. A per-session UI selector switches back to strict validation with one click; sessions keep their own mode.
- Bound evidence transport: the recent-observation partition is one quarter of the input budget under a 96KiB ceiling (configurable via context.observation_budget). Summarization runs only on overflow and archives recoverable sources under .tool-results/.
- Isolate one-shot tasks: POST /v1/tasks without an explicit session no longer inherits the shared default transcript, cutting first-round prompt size roughly in half.
- Short-circuit verified write read-backs: a byte-verified write receipt answers an immediate head read with a content echo, skipping the disk read and extra model round while keeping artifact acceptance gates accurate.
- Make long runs convergent and observable: a 128-round backstop for unlimited rounds, normalized model matching, reasoning_content logging and thinking metadata moved below the reply.
- Bound image payloads: small images keep exact bytes, larger frames downscale through a quality and dimension ladder, and a request-level budget (4 visual items, 1.6MB base64) returns a clearly attributed 413 instead of an opaque provider error.
- Output image viewer zoom: enlarge/shrink buttons, plain scroll-wheel zoom, fit reset and a live percentage label.

Packages include the Windows x64 installer, Linux x64 and ARM64 portable archives, and macOS x64 and ARM64 ZIP and PKG installers.
